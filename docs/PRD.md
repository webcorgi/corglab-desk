# CORGLAB Desk — PRD
Goal: sell an AI-assisted inquiry and quote management SaaS alongside CORGLAB website builds.
Visitor can submit name, email, company and message; operator can list and update status; optional AI labels and summarizes inquiries.
MVP acceptance: validated REST API, database persistence, simple React front end, Docker local stack.
Commercial readiness: real auth and access controls, organization isolation, spam controls, consent and retention, migrations, mail queues/retries, monitoring, HTTPS, CI/CD, recovery tests.
Hypothesis: trial subscription ₩29,000/month; unvalidated price.
